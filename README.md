# Clash Go

基于 Go、MyGo 和 mihomo 的桌面代理工具。

## 框架

- **Go**：应用逻辑与内核管理。
- **[MyGo](https://github.com/egoist/mygo)**：使用 `mygo/ui` 构建原生桌面界面，跟随系统明暗主题。
- **[mihomo](https://github.com/MetaCubeX/mihomo)**：代理内核，独立运行，通过本机鉴权 REST API 管理。

## 功能

### 概览

- 查看内核状态、版本、运行时间和活动连接数。
- 显示累计上传、下载流量及采样速率。
- 启动、停止内核，切换规则、全局和直连模式。

### 代理组

- 查看和搜索代理组，切换手动选择组的节点。
- 自动选择组由内核管理。
- 支持节点或代理组延迟测试，可自定义 HTTPS 测试地址。

### 配置

- 添加 HTTPS 订阅，自动识别配置名称。
- 导入本地 mihomo YAML，独立保存多个配置并记忆当前选择。
- 支持配置切换、重命名、删除、YAML 编辑和导出。
- 手动更新订阅，每次填写订阅地址，不保存订阅链接。
- 保存前校验配置，切换或更新失败时尝试恢复原配置运行。
- 全部配置本地备份，恢复时追加配置，不覆盖已有配置。

### 连接

- 查看活动连接的目标地址、进程、流量、匹配规则和代理链。
- 按域名、IP、进程、规则或代理链搜索。
- 按连接时间、上传量或下载量排序。
- 关闭单条连接，或确认后关闭全部连接。

### 规则与资源

- 按匹配顺序查看生效规则，支持搜索和分页。
- 查看代理与规则资源的条目数、类型和更新时间。
- 手动更新 HTTP 资源，对代理资源执行健康检查。

### DNS 工具

- 使用内核解析器查询 A、AAAA、CNAME、MX、TXT、NS 和 PTR 记录。
- 清空 DNS 缓存。

### 日志

- 查看最近 64 KiB 的内核日志。
- 支持关键词过滤、暂停显示、清空和导出。

### 内核与设置

- 首次自动下载 mihomo，支持版本检查、更新和 SHA-256 校验。
- 内核更新失败时回滚，运行中更新恢复原模式和节点选择。
- 已有配置自动启动，正常退出时停止内核。
- 自定义本机 HTTP / SOCKS5 混合端口，默认 `127.0.0.1:7890`。
- 支持单实例运行、设置保存和端口冲突检查。
- 仅提供本机代理，不自动修改系统代理，不启用 TUN 或局域网监听。
